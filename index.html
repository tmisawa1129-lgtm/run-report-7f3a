メモ

指摘やアドバイスをもらったら、ここに追記していきます

2026.08.24 ／ 8/24のランについて
  • ピッチが上がったことで接地時間が短くなったのは、意識した結果
  • 平均より速いペースで、かつ慣れないフォームなのに、平均心拍がほぼ同じだった点が良い
  • 総評は「めちゃくちゃ良いラン」
2026.08.25 ／ 心拍ゾーンの設定について（記録のみ）
  • 時計の心拍ゾーンは初期設定のまま（220−年齢＝最大心拍184で計算されている）
  • 実測の最大は192（7/26のワークアウト）。8/07に180。ランでの最大は169
  • 設定を192にすると、7〜8月のZone 2は 45.8% → 48.6% に変わる（Zone 1は21.4%→30.2%）
  • ただし筋トレ中の光学式心拍は誤検出しやすく、192の信頼性は不明
  • 本レポートの数値はすべて初期設定（184）のままで計算している

指摘の中心はペースと心拍の関係だった。ピッチや接地時間は意識すれば動かせるが、同じ心拍のまま速く走れたことは意識では作れない。フォーム変更が有酸素効率の向上として出ていることになる。

  • 当時の確認点「距離が伸びてもピッチを維持できるか」「速く走る日に維持できるか」は、8/27・8/30でどちらも確認できた（3.67km 5'14"／15.02km 5'35" ともピッチ168）
2026.09.01 ／ 9月最初のラン
  • 5.14km / 40:03 / 7'47" / 心拍123
  • ピッチ171・Zone 2率97%（39分02秒）でどちらも最高値
  • メトロノームを聴きながら走った。ケイデンスのばらつきが明らかに小さい
  • 歩幅は74cmで、8月ジョグ平均77cm・8/24-25の76cmよりさらに縮んだ
  • ラップは 7'08" → 9'26" と落ちたが、心拍は119〜124で一定。Zone 2を守った結果

9/3（3日連続・人と一緒に走った日）：4.93km / 41:27 / 8'25" / 心拍117。Zone 2率85%（35分26秒）。相手のペースに合わせたため、ペース・ピッチ・心拍がいずれも下がっている（ピッチ 171→169→165、心拍123→123→117）。歩幅は71cmで9/2と同じなので、遅くなったぶんはピッチで調整されている。1km目を9'20"（心拍109）とゆっくり入り、2km目以降は8'11"〜8'14"・心拍117〜120で安定した。

9/2（2日連続）：4.98km / 41:03 / 8'15" / 心拍123。Zone 2率97%（40分04秒）で2日連続。ピッチ169、歩幅71cm、上下動8.4cmはいずれも直近で最小。ラップの心拍が 122・122・123・122・122 とほぼ完全に一定だった。
